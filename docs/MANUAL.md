## 用語

| 用語 | 意味 |
| --- | --- |
| ボーカル | 曲の中の歌声 |
| 伴奏 | 曲からボーカルを除いた部分（楽器/ドラムなど） |
| 抽出 | 曲をボーカルと伴奏に分離すること |
| モデル | 抽出に使用するデータ。初回にダウンロードし、ブラウザに保存する |
| 一覧 | 追加した曲の並び。上から順に抽出する |

## 基本の流れ

1. **追加する**: 曲のファイルを画面にドラッグ＆ドロップするか、「ファイルを選択」「追加」（Ctrl+O）で選択する。複数のファイルを一括で追加できる
2. **設定する**: モデル、抽出するもの、形式を選択する
3. **抽出する**: 「すべて抽出」をクリックする。上から 1 曲ずつ抽出する。1 曲のみ抽出する場合は、その行の「抽出」をクリックする
4. **試聴する**: 完了した曲の ▶ で結果を再生する
5. **保存する**: 行の「ボーカル」「伴奏」で個別に、「すべて保存」で一括で保存する

## 対応ファイル

| 種類 | 例 |
| --- | --- |
| 音声ファイル | WAV、AIFF、MP3、M4A（AAC）、FLAC、Ogg など（ブラウザによって読み込めない形式がある） |
| 動画ファイル | MP4（音声のみを使用する） |

## オフラインとデータの保存

- 曲は端末の外部に送信されない。抽出はすべてブラウザ内で行う
- モデルは初回の抽出時にダウンロードし、ブラウザに保存する。2 回目以降はダウンロードしない
- 一度開いたあとは、オフラインでも利用できる（使用するモデルを保存済みの場合）
- ブラウザの「インストール」（ホーム画面に追加）で、アプリとして起動できる
- 閉じたあとも、一覧と結果を保持できる（[設定](#設定) の「データ」）

## 抽出の設定

| 項目 | 内容 |
| --- | --- |
| モデル | 軽量（約 38MB）、標準（約 50MB）、高精度（約 75MB）。サイズが大きいほど分離の精度は上がるが、ダウンロード量も増える |
| 抽出するもの | ボーカルと伴奏、ボーカル、伴奏 |
| 形式 | WAV、MP3、Opus。WAV のビット数と MP3 / Opus のビットレートは設定で指定する |

- 抽出中は変更できない
- 曲を約 12 秒ずつに分割して処理するため、長い曲やスマホでも抽出できる

## 一覧の操作

| 操作 | 動作 |
| --- | --- |
| すべて抽出 | 待機中の曲を上から順に抽出する |
| 抽出（行） | その曲のみを抽出する。失敗した曲の再実行にも使用する |
| 中止 | 抽出を停止する。途中までの結果は破棄する |
| ▶ / ■ | 結果を再生する / 停止する。同時に再生できるのは 1 つのみ |
| × | 曲を一覧から削除する（抽出中の曲は削除できない） |
| 「ツール」→「一覧を空にする」 | すべての曲を削除する |

モデルを初めて使用するときは、抽出の前に「モデルを取得中… ○%」と表示される。

## 保存

| 操作 | 内容 |
| --- | --- |
| 行の「ボーカル」「伴奏」 | その結果を個別に保存する |
| すべて保存 | 抽出した結果を、一括で `wevocalextractor.zip` として保存する |

- ファイル名は「元のファイル名_vocals」「元のファイル名_accompaniment」になる
- 形式は、抽出時に選択していた形式になる

## 設定

「ツール」→「設定…」（スマホは「⋮」→「設定」）。

<img src="images/settings.png" alt="設定画面。左に分類と検索欄、右に項目が並ぶ" width="640">

| 分類 | 項目 |
| --- | --- |
| 全般 | テーマ（システムに合わせる、ライト、ダーク）、言語、アップデートの確認 |
| ボーカル抽出 | WAV の形式（16bit / 24bit / 32bit float）、ビットレート（MP3 / Opus。128〜320 kbps）、GPU（WebGPU）を使う、高音域を残す |
| データ | 閉じたあとも一覧を残す、ダウンロードしたモデルの削除、残した一覧の削除 |
| 開発者向け | ダイアログの表示 |

| 項目 | 内容 |
| --- | --- |
| GPU（WebGPU）を使う | 対応しているブラウザでは処理が速くなる。利用できない場合は CPU で処理する |
| 高音域を残す | 約 11kHz 以上を残す。声は明るくなるが、伴奏が混入しやすい |
| 閉じたあとも一覧を残す | 未ダウンロードの結果のみ（既定）、ダウンロードした結果も、残さない |

設定画面の操作（検索、OK/キャンセル/適用、すべて既定値に戻す）は WeVocalSynth と共通である。

## キーボード操作

| キー | 動作 |
| --- | --- |
| Ctrl+O | ファイルを追加する |
| Alt / F10 | メニューバーに移動する |

ファイルは画面のどこにドロップしても追加される。一覧は「ヘルプ」→「ショートカット一覧」でも確認できる。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 声と伴奏が正しく分離されない | モデルを「高精度」に変更する |
| 抽出したボーカルにシンバルなどが混入する | 「高音域を残す」を OFF にする |
| 抽出したボーカルがこもって聞こえる | 「高音域を残す」を ON にする |
| 抽出が遅い | モデルを「軽量」にするか、「GPU（WebGPU）を使う」を ON にする |
| 抽出が失敗する/結果が不正確 | 「GPU（WebGPU）を使う」を OFF にする。スマホではモデルを「軽量」にする |
| ファイルを開けない | WAV か MP3 に変換してから追加する |
| ブラウザの容量が不足する | 設定の「データ」で、使用しないモデルや残した一覧を削除する |
